# 📦 Product Manager

A simple, accessible web app to save and manage products using the browser's local storage.

## ✨ Features
- ➕ Add, edit, and delete products
- 🌙 Dark mode with persistence
- ⌨️ Keyboard shortcuts (`/`, `Alt+R`, `Alt+D`, `Escape`, `?`)
- 💾 Auto-saves input fields
- 📱 Fully responsive (mobile, tablet, desktop)  //nearly responsive 😅
- ♿ Accessible (skip link, ARIA labels, focus management)

## 🔧 Tech Stack
- HTML
- CSS (rem/em units, flexbox, media queries)
- JavaScript (vanilla, localStorage)

## ⌨️ Keyboard Shortcuts
| Shortcut | Action |
|----------|--------|
| `/` or `Alt+R` | Focus the form |
| `Alt+D` | Toggle dark mode |
| `Escape` | Cancel editing |
| `?` | Open shortcuts help |

## 📝 What I Learned
- Building an accessible web app
- Using `localStorage` for persistence
- Implementing keyboard shortcuts
- Responsive design with `rem`/`em` units
- Dark mode with CSS classes
